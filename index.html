💡 ចុចលើរូប 🔊 ដើម្បីស្តាប់ការបញ្ចេញសំឡេងតួកគីជាក់ស្តែង

ℹ️ ចំណាំអក្សរពិសេសក្នុងភាសាតួកគី (Key Sounds)

Ç, ç = សំឡេង "ច" (ch)
C, c = សំឡេង "ជ" (j)
Ş, ş = សំឡេង "ឞ / ស្ស" (sh)
Ğ, ğ = g ទន់ (ពន្យារស្រៈមុខ)
I, ı (គ្មានចុច) = សំឡេង "អ៊ឺ/ឺ"
İ, i (មានចុច) = សំឡេង "អ៊ី/ី"
Ö, ö = សំឡេង "អឺ" (មាត់មូល)
Ü, ü = សំឡេង "អ៊ូ/អ៊ឺ" (មាត់មូល)

☀️ ការសួរសុខទុក្ខតាមពេលវេលា (Greetings) ចុចលើប៊ូតុងដើម្បីស្តាប់សំឡេង

🗣️ ឃ្លា និងទម្រង់ប្រយោគកម្ម៉ង់អាហារ (Ordering Phrases)

☕ ភេសជ្ជៈពេញនិយម (Drinks - İçecekler)

🍲 មុខម្ហូប និងបង្អែមល្បីៗ (Food - Yemekler)
